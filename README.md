# Deen One

Application islamique éducative entièrement gratuite, sans abonnement Premium.

## Prototype mobile

Première version en cours de publication : calendrier islamique, lecture du Coran, apprentissage de l'arabe et exercices.

Les connexions Google/Apple, le suivi partagé des élèves et la correction automatique de récitation ne sont pas encore fonctionnels.

## Déploiement

Publier les fichiers du prototype à la racine du dépôt, puis activer GitHub Pages dans Settings > Pages, avec la branche `main` et le dossier `/(root)`.

Adresse prévue : https://demirerol35-max.github.io/Denn-one/

Ne pas publier de données personnelles d'élèves, de mots de passe ou de clés API dans ce dépôt public.
